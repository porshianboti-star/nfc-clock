שעון נוכחות NFC

גרסת ניסיון
נוכחות בהצמדה אחת. בלי אפליקציה.

מדביקים מדבקת NFC בכניסה לאתר, למפעל או למוסד. העובד מצמיד את הטלפון, דף קטן נפתח לבד, והנוכחות נרשמת עם שעה, שם ומיקום. המנהל רואה הכול בטבלה חיה.

  • בלי התקנה לעובד. שולחים לו לינק אישי בוואטסאפ פעם אחת, וזהו.
  • בלי חומרה. מדבקת NFC רגילה בכמה שקלים, אפשר להדביק גם על שלט או דלת.
  • כמה אתרים שרוצים. כל מדבקה מקבלת שם מיקום, והטבלה מראה מי היה איפה ומתי.

פתיחת דשבורד לעסק

תקבל לינק ניהול סודי. מי שמחזיק בו מנהל את החשבון, אז שמור אותו כמו סיסמה.

הדשבורד מוכן

זה לינק הניהול שלך. שמור אותו עכשיו (סימניה, מנהל סיסמאות, מייל לעצמך). אין דרך לשחזר אותו.

פתח את הדשבורד

איך זה עובד

  1. פותחים דשבורד ומוסיפים את המיקומים (״בית ספר אלונים״, ״מחסן״). לכל מיקום נוצרת כתובת ייחודית.
  2. כותבים את הכתובת על מדבקת NFC (מהדשבורד בטלפון אנדרואיד, או עם אפליקציית כתיבה חינמית) ומדביקים בכניסה.
  3. מוסיפים עובדים ושולחים לכל אחד את לינק ההתקנה האישי שלו. פתיחה אחת מחברת את הטלפון.
  4. מכאן העובד רק מצמיד. אתם רואים שעה, שם ומיקום בזמן אמת ומייצאים לאקסל.
