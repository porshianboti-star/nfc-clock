אחרי ההוספה שולחים לעובד את לינק ההתקנה האישי שלו. פתיחה אחת בטלפון, וזהו.

הוספת מיקום (מדבקה)

כדאי ללחוץ ״קח את המיקום הנוכחי״ כשאתה עומד ליד המדבקה. ככה רישום מרחוק מסומן למנהל.

מיקוםקודGPS

איך כותבים את הכתובת על המדבקה

  • אנדרואיד (Chrome): לחץ ״כתוב למדבקה״ ליד המיקום, הצמד מדבקה ריקה לגב הטלפון.
  • אייפון: התקן אפליקציית כתיבה חינמית (למשל NFC Tools), בחר Write ← Add a record ← URL, הדבק את הכתובת שהעתקת, לחץ Write והצמד.
  • מדבקה שכבר נכתבה אפשר לכתוב מחדש. על דלת מתכת צריך מדבקה עם גב אנטי-מתכת, או להדביק על שלט פלסטיק.

ייצוא לאקסל (CSV)

הקובץ נפתח באקסל בעברית תקינה. עמודות: תאריך, שעה, שם, מיקום, סוג, מרחק מהמדבקה, דגלים, מקור, הערה.

לינק הניהול
